# Orivra — MailWeave experimental beta

**Public experimental prerelease — not Google-approved and not a stable release.**

Orivra helps AI agents navigate large information spaces, find relevant evidence, and
understand what happened and why. **MailWeave is the first connector: read-only Gmail tools
for Claude Desktop.**

Ask about a decision, read the messages behind it, and follow the conversation beyond a
search preview. MailWeave returns message references, available receipt timestamps, thread
relationships, and limits on what was retrieved. Claude uses that evidence to write the answer;
neither the connector nor the beta label guarantees correctness.

## Install

Requires an **Apple Silicon Mac, macOS 14+, and Claude Desktop with custom extensions enabled**.

1. Download `Orivra-Beta-0.2.0-beta.1.mcpb` from this release's assets. The source ZIP is not
   the installer.
2. In Claude Desktop: **Settings → Extensions → Advanced settings → Install Extension…**
3. In a new chat, ask **“Set up Orivra.”** Open the Google authorization link on the same Mac
   and review the read-only permission for your account.
4. Return to Claude and ask **“Continue the Orivra setup.”** Wait for the local model download
   and the ready message before asking about your mail.

No Terminal or personal Google Cloud project is needed for this packaged path. The
[full installation guide](https://github.com/NayanKanaparthi/Orivra/blob/main/docs/INSTALL_DESKTOP_BETA.md)
also explains reconnecting, removing the extension, and revoking Gmail access. The
[self-managed path](https://github.com/NayanKanaparthi/Orivra/blob/main/docs/SETUP.md) remains available.

## Before you connect

- **Google data-access verification is incomplete.** Expect an unverified-app warning where
  Google permits authorization, a 100-total-user cap, and possible account/administrator
  restrictions. Consent is not Google approval of the app or an exemption from its requirements.
- **Selected email goes to Claude/Anthropic.** Retrieval runs locally, but the overall assistant
  is not device-only. Review the [privacy policy](https://www.nayankanaparthi.dev/orivra/privacy)
  and [terms](https://www.nayankanaparthi.dev/orivra/terms) before granting access.
- **Experimental, not general availability.** Calls may fail or return incomplete evidence.
  Verify consequential answers. Gmail only; no Slack or Drive support in this build.
- **Known engineering gaps remain.** CI and release acceptance are not fully green. The
  [known limitations](https://github.com/NayanKanaparthi/Orivra/blob/main/docs/KNOWN_LIMITATIONS.md)
  and [launch record](https://github.com/NayanKanaparthi/Orivra/blob/main/docs/releases/LAUNCH_PACKET_0.2.0-beta.1.md)
  distinguish tested behavior from unverified claims, including the open runtime network-boundary check.
