# Orivra — MailWeave beta 0.2.0-beta.1

**Private release draft. Not publicly published or tagged.** Destination:
[NayanKanaparthi/Orivra](https://github.com/NayanKanaparthi/Orivra).

Orivra is being built to help AI agents navigate large information spaces, find relevant
evidence, and understand what happened and why. This beta starts with **MailWeave**, the
read-only Gmail connector, packaged for Claude Desktop on Apple Silicon Macs.

## In this beta

- Install a desktop extension with its own Python runtime; no Terminal or user-created
  Google Cloud project is needed for the packaged path.
- Authorize your own Gmail account through Google, with `gmail.readonly` only.
- Download the pinned local retrieval models through the setup tool.
- Search mail, map threads, and read selected messages with references, available timestamps,
  attribution provenance, and explicit disclosure limits.
- Inspect and follow the query-time evidence graph through Orivra's tools.

Only Gmail is connected in this release. Graph availability is not a measured claim that it
improves answer quality. The connector retrieves evidence; Claude generates the answer.

## Installation

Requires **Apple Silicon / macOS 14+**, Claude Desktop with custom extensions allowed, and an
internet connection for Gmail and initial model setup. Intel Macs, Windows, and Linux are not
supported by this installer.

Once the maintainer supplies the approved file, follow the
[installation guide](../INSTALL_DESKTOP_BETA.md): install the `.mcpb`, ask **“Set up Orivra”**,
complete Google consent in a browser on the same Mac, then ask **“Continue the Orivra setup”**.

The [self-managed command-line path](../SETUP.md) remains available for people who want their
own Google Cloud project and OAuth client.

## Evidence and limits

The owner reports successful installation and setup of the earlier candidate on their Mac.
The MIT rebuild has not been reinstalled in Claude Desktop. Its inspection found no problems;
all 169 packaged product Python source files and the manifest's tool list match its build
inputs. Runtime sources, native binaries, launcher, and OAuth client are unchanged. Three
dependency bytecode caches differ in serialization but hold equal code objects under CPython
3.12.14. These checks are not a new live install or a broad answer-quality benchmark.

Earlier live checks on a seeded test mailbox supported a multi-message decision and Gmail
receipt ordering for selected cross-thread pairs. They do not establish speed, completeness
across mailboxes, or an advantage over other connectors. A response may be capped, partial,
or declined; check the cited evidence before relying on an answer.

## Permissions and privacy

The installer contains the app's Desktop OAuth client, not a user's Gmail authorization.
Each user consents separately. The local token store is permission-restricted, not encrypted
by the app. Selected email evidence is passed to Claude/Anthropic; local retrieval does not
mean the entire assistant is offline. See the
[privacy policy](https://www.nayankanaparthi.dev/orivra/privacy) and
[terms](https://www.nayankanaparthi.dev/orivra/terms).
